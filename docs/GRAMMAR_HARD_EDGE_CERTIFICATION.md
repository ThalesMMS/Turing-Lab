# Grammar hard-edge certification

Issue #336 has a deterministic, local-only grammar-family matrix. It is
independently authored against the live Turing Lab APIs. JFLAP remains a
documented behavioral parity reference; this family does not copy or claim to
derive fixture content from JFLAP.

Run the complete family from the repository root:

```text
dart run tool/hard_edge_grammar_cases.dart run
dart run tool/hard_edge_grammar_cases.dart repeat
dart run tool/hard_edge_grammar_cases.dart mutate
```

`run` writes stable JSON and Markdown to
`build/qa/grammar-hard-edge/`. `summary` emits algorithm/property/seed
coverage. `replay` and `shrink` accept a repo-confined counterexample artifact.
All reports set `remotelyVerified` to `false`.

The central hard-edge runner can register
`GrammarHardEdgePropertyExecutor` from
`tool/hard_edge/families/grammar_adapter.dart`. Its descriptors are one case per
algorithm/property, and its materializer replaces only the seed in the strict
family fixture. The same file exposes `GrammarCounterexampleShrinker` and the
grammar mutation executor.

## Oracles and mutation threshold

The independent oracle performs a bounded breadth-first enumeration of
sentential forms and does not invoke a production parser. Applicable parser
results must agree with it. A bounded-unknown or tokenization result is recorded
as incomplete and cannot certify a parser outcome. Transformation checks
enumerate both source and result grammars. Insertion order and nonterminal
renaming are metamorphic inputs.

The three semantic mutation probes (`drop-epsilon-production`,
`substitute-start-symbol`, and `shortest-match-tokenizer`) alter real parser or
tokenizer inputs and must all be killed. The required threshold is 3/3, with
zero survivors. Any future survivor makes `mutate` fail.

Family fixtures are generated by the strict central catalog builder and carry
their SHA-256 digest, Apache-2.0 license, and `LICENSE.txt` basis in the central
manifest. There is no separate reviewed fixture outside that catalog.
The `parser-replay-shrink-fixture` case embeds the exact grammar, input, seed,
and property evaluated by the Earley/independent-oracle path. Central shrink
dispatch should use `GrammarFailureFixtureShrinker` with
`grammarFailureFixtureIsValid` and `grammarFailureFixtureIsApplicable`; these
preserve the fixture schema and parser property while reducing both the input
and productions. Other grammar case fixtures are validated against their
descriptor and treated as already-minimal fixed artifacts, so central shrink
can replay and preserve them without applying an unrelated JSON reduction.

The certification found and fixed these pre-existing defects:

- recursive descent interpreted mixed RHS symbols as nonterminals and rejected
  `S -> id Tail`;
- CNF conversion retained structurally duplicate productions reached through
  different unit/epsilon provenance paths;
- GNF cleanup treated the start symbol's terminal production as a generated
  wrapper and deleted the start language;
- CFG unit-cycle reduction repeatedly derived a new self-unit production and
  did not terminate;
- reduction renamed unchanged productions on every pass, breaking
  idempotence;
- CNF helper allocation could collide with existing `N0`/`T0` grammar symbols.
- Earley could throw on an empty production LHS and did not expose timeout as a
  typed outcome;
- CYK reported tokenization failures and timeouts as ordinary rejection or a
  generic failure string.

## Limits

Seeds are unsigned 32-bit values; a run accepts 1 through 64 seeds and a
bounded word length from 0 through 6. The complete default uses four seeds and
length three. Recursive descent reports `timedOut`, never `rejected`, when its
deadline expires. LL(1) cancellation, timeout, and step limits; canonical LR(1)
construction time, item, and state limits plus parse cancellation, timeout, and
step limits; every brute-force search limit; and user-derivation hint
cancellation and depth bounds are separately typed. TM conversion is exercised
at an explicit construction bound so the local command cannot expand an
unbounded grammar.
